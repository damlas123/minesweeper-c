# 💣 C-Based Minesweeper Game (Mayın Tarlası)

C programlama dili kullanılarak konsol ortamı için sıfırdan geliştirilmiş klasik Mayın Tarlası oyunu.

## 🚀 Proje Hakkında
Bu proje, C dilindeki temel programlama mantığını, matrisler (iki boyutlu diziler) ve koşullu yapıları pekiştirmek amacıyla geliştirilmiştir. Kullanıcının koordinat girerek mayınlardan kaçmaya çalıştığı interaktif bir konsol oyunudur.

## 🛠️ Kullanılan Teknolojiler ve Araçlar
- **Dil:** C
- **Geliştirme Ortamı / Derleyici:** Dev-C++ (Makefile ve Dev dosyaları dahildir)

## 🎮 Nasıl Oynanır?
1. Repoyu klonlayın veya `Mayin tarlasi.exe` dosyasını çalıştırın.
2. Konsol üzerinden satır ve sütun koordinatlarını girerek tarladaki güvenli alanları açmaya çalışın.
